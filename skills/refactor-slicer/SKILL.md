# Refactor Slicer Skill

Plan a safe refactor for one oversized file.

## Produce

- responsibility map
- safest extraction order
- exact first cut
- risks and stop lines
- verification after each step

## Rules

- preserve behavior
- extract before redesigning
- one concern per phase
- start with pure helpers, then orchestration, then UI or transport
