# Test Gap Auditor Skill

Audit the highest-value missing tests in the codebase.

## Focus on

- API boundary validation
- DB mappers
- queue actions
- AI parsing and generation flows
- migration-sensitive behavior
- public success/error contracts

## For each finding

- identify the risky code path
- explain what is untested
- explain the likely failure mode
- recommend the exact first test to add
